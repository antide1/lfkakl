# Click Frames

Мод для Geometry Dash (Geode) в духе «счётчика кадров клика»: показывает,
сколько кадров держится каждое твоё нажатие, цветными строками в углу и
кружками прямо на месте клика.

Важно: это **не** копия FB Counter. Тот мод — большой закрытый C++ проект
(анализ кликов на сервере fbmod.com, запись макросов, ffmpeg и т.д.), его
невозможно повторить «один в один». Здесь написана своя маленькая реализация
одной функции — живого подсчёта кадров клика, без макросов и без сети.

## Что делает мод

- Строки-счётчики в углу: по умолчанию `1, 2, 3, 4, 5-6, 7-8, 9-12, 13-16, 17+`,
  у каждой свой цвет. Список строк и цвета задаются в настройках.
- Кружок с числом кадров на месте каждого клика (можно отключить или сделать
  исчезающим).
- Строчка «last click: N frames» с последним кликом.
- При рестарте уровня счётчики и кружки сбрасываются.

## Как считается кадр

Кадр = один шаг обновления уровня, то есть реальная частота физики игры.
На 60 FPS это 60 кадров в секунду; с TPS bypass (например, Eclipse: Physics
Bypass) на 240 — один кадр это 1/240 секунды. Мод ничего не ускоряет и не
требует bypass.

## Как получить готовый .geode (сборка в GitHub Actions)

Компилятор на этом ПК не установлен, поэтому .geode собирается в облаке —
бесплатно и без установки Visual Studio.

1. Зарегистрируйся/зайди на GitHub и создай новый репозиторий (можно Private).
2. Загрузи в него содержимое этой папки. Проще всего:
   - распакуй `click-frames.zip`;
   - на странице репозитория: **Add file → Upload files**;
   - перетащи туда **всё содержимое** папки, включая скрытую папку `.github`
     (в ней лежит workflow сборки);
   - **Commit changes**.
3. Открой вкладку **Actions** → workflow **Build Geode Mod** → **Run workflow**
   (можно и просто дождаться автозапуска после коммита).
4. Через 5–10 минут открой завершённый запуск, внизу в разделе **Artifacts**
   скачай `click-frames-geode` — это zip, внутри лежит `ClickFrames.geode`.
5. Распакуй и положи `.geode` в:
   `%LOCALAPPDATA%\GeometryDash\geode\mods`
   (либо в игре: Geode → Mods → Install from file).
6. Перезапусти игру. В настройках мода Geode появятся все параметры.

Если при сборке будет ошибка — пришли лог из Actions, поправлю код.

## Сборка локально (необязательно)

Нужны: Visual Studio (C++ workload), CMake, Ninja и Geode SDK.

```powershell
git clone --recurse-submodules https://github.com/geode-sdk/geode.git
$env:GEODE_SDK = "$PWD\geode"
cd click-frames
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Готовый `.geode` появится в `build/`.

## Файлы

- `src/main.cpp` — весь код мода.
- `mod.json` — метаданные и настройки.
- `about.md`, `changelog.md`, `logo.png` — страница мода.
- `.github/workflows/build.yml` — сборка .geode в GitHub Actions.

## Настройки

| Ключ | Что делает |
| --- | --- |
| Show click frames | главный выключатель |
| Counter rows | какие строки показывать (`1,2,3,7-8,17+`) |
| Row colours | цвета строк (`1:fe4f50,5:8bfe8b`) |
| Click circles | кружки на месте кликов |
| Last click readout | строка с последним кликом |
| Rows position X/Y | положение строк в процентах экрана |
| Rows scale | размер строк |
| Circle text scale | размер числа в кружке |
| Circles disappear after | через сколько секунд кружок исчезает (0 — до рестарта) |

Настройки читаются при старте уровня: после изменений перезайди в уровень.
